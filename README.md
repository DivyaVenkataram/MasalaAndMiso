# Masala & Miso

Masala & Miso is a Michelin-style food blog offering thoughtful, critical reviews of restaurants recognized by the Michelin Guide, with a focus on flavor, experience, and cultural storytelling.

## Run locally

Open `index.html` in a browser, or serve the project with any static server:

```bash
# Python 3
python -m http.server 8000

# Node (npx)
npx serve
```

Then visit `http://localhost:8000` (or the port shown).

## Site structure

- **Home** — World map with restaurant pins (America-focused), intro, and recent standout reviews
- **Blog** — In-depth reviews with tasting notes and culinary language
- **Rankings** — Filterable table by location, price, cuisine, Michelin stars; reservation (affiliate) links
- **Best Of** — Curated lists by city, experience, and budget; includes Dining Philosophy
- **About** — Credentials, background (e.g. grew up in Tokyo), sponsors, Michelin recognition, quotes
